# Student quick start

**This is a 9-month study plan at 20 planned hours per week**, not a claim that the short pilot readings already contain 720 hours of finished instructional material.

1. On the **Dashboard**, click **Continue learning**.
2. On a published week, use **Tue, Wed, Thu, Fri** to move through its four class readings.
3. Read the concept explanations, then perform the numbered guided steps. Use a permitted VM or offline simulation when indicated.
4. Check each completed lab task, record actual observations under **Your private notes**, and check **Mark class completed** only when the day's work is done.
5. Open **Assessment** to take that week's original graded practice quiz. Review each answer explanation and retry missed topics.
6. Open **My workspace** to see your saved notes and results. Use **Export progress** frequently so your work survives browser resets.
7. On another device, open the same hosted course link and **Import progress**. Import overwrites the device's current local saved record; export that first if needed.

**Course status:** Lessons and quizzes are currently complete enough to pilot for Weeks 1–4. Weeks 5–36 are only blueprint previews until original lesson packets are authored. No grades from a public site constitute certification or accredited academic credit.

**Lab safety:** The course never requires access to another person's system or any production warehouse device. Use isolated VMs and fictional data; do not upload passwords, real customer details or security logs to GitHub.
